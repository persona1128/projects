# 一个轻松的游戏

一款可在浏览器中游玩的中文剧情与战斗小游戏，包含三段战斗、角色对白、音乐和结局。

## 开始游玩

进入 [`demo/`](demo/) 目录，在 macOS 上双击 `启动游戏.command`。也可以在该目录运行：

```sh
python3 tools/serve_game.py
```

启动器会在本机打开游戏；需要 Python 3。操作方式、资源说明和开发记录见 [`demo/README.md`](demo/README.md)。

## 项目内容

- `demo/`：可运行的游戏源码、资源与构建工具。
- `文本.md`：剧情原文。
- `游戏框架.md`、`游戏设定_可修改版.md`：设计文档。

本地的 `发布包/` 是上述游戏的打包副本，未纳入源码仓库。
