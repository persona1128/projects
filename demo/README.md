# 一个轻松的游戏 · 本地试玩

双击本文件夹的 **启动游戏.command**，它会启动仅在本机运行的服务并在默认浏览器打开游戏。游戏不需要联网；启动时需要本机的 Python 3。直接用 `file://` 打开 **index.html** 时，应用内浏览器可能不播放任何声音。

## 操作

- 方向键 / WASD：移动。Z：长按念力。X：长按歌声。两者同时按下时优先歌声。
- C：吃葡萄恢复 20 HP，可同时攻击；满血不消耗。
- 点击画面 / 空格 / Enter：继续剧情。
- Esc：暂停。切换窗口自动暂停。右上角可静音。
- 失败后可重试本关（恢复入关时状态）或从头开始。

网页侧边的操作指南与触屏键位在开场时隐藏，读完拉鲁拉丝询问“您还记得您的王牌招式吧？”后显示。

完整流程包含 167 条剧情、三个战斗关卡、失败画面和结局。初始 100 HP、5 颗葡萄，关卡之间不自动补充。页面底部显示“一个轻松的游戏260930”与“Crafted with AI by ChrisChi”。

### 美术如何替换

同名同格式的资源可直接覆盖；文件名或格式不同则改 `config.js` 的 `assets` 路径。支持浏览器能够解码的 PNG、WebP、JPG、SVG；音频可用 WAV、MP3 等。不要仅将 PNG 的后缀改为 SVG。

| 资源 | 当前规格 | 建议 |
| --- | --- | --- |
| 背景 | 960 × 720 | 保持 4:3；不透明整图；村庄中央留战斗空间 |
| 立绘 | 480 × 640 | 透明背景；同一角色两种表情尺寸、站位一致 |
| 沙奈朵行走 | 100 × 100 SVG，色块与描边风格同敌人 | `gardevoir-0.svg` 至 `gardevoir-3.svg`，朝上；移动时摆臂、裙摆和迈步 |
| 喷火龙待机 | 同上 | `charizard-0.svg` 至 `charizard-3.svg`，面向左；循环扇翼、呼吸和尾焰 |
| 敌人 | 100 × 100 | 透明背景，主体居中；Boss 游戏内放大显示 |
| BGM | MIDI 原件及 22.05 kHz WAV 合成版 | 按剧情对白切换，播放期间单曲循环；`slg_engi.wav` 为单声道，以符合静态托管单文件大小限制 |
| 音效 | 短 WAV | 尽量短，避免尾音过长 |

行走图与待机动画使用独立帧路径数组；帧数自动读取 `config.js` 中的路径数组；沙奈朵移动时每秒 9 帧、喷火龙待机每秒 7 帧。`sprites/gardevoir.svg` 和 `sprites/charizard.svg` 与第 0 帧一致，实际运行使用带 `-0` 至 `-3` 的四张矢量动画帧。

### 后续修改设定与剧情

1. 修改上级文件夹的 **游戏设定_可修改版.md**，然后让我据此更新实现。Markdown 不会自动驱动游戏。
2. 剧情正文只改上级文件夹的 **文本.md**，保留 A–D 标题。
3. 用已安装的 Python 3 运行 `python3 tools/build_data.py`，或让我执行同步；之后刷新游戏。普通玩家无需执行这一步。
4. 若手动调数值，修改 `config.js`，并把相应值记回设定文档，避免版本不一致。

当前背景切换和喷火龙出场依赖剧情中的关键词，具体见新版设定文档。修改这些句子时需同步更新代码。
